Everything you need to normalize resumes

📋
Locked Output Format
Every result follows the exact same structure — no variation, no surprises. Copy-paste ready every time.
🧮
Tenure Calculation
Automatically computes years and months for each role, including present-day jobs calculated up to today.
⏳
Gap Detection
Identifies unemployment gaps between jobs — and flags how long the candidate has been out of work if currently unemployed.
🔀
Overlap Detection
Catches when a candidate started a new job before leaving the previous one and notes the overlap duration.
🏢
Company Grouping
Multiple roles at the same company are merged into a single entry, keeping the output clean and readable.

// output format

One format.
Always.

The output structure is locked and never changes — making it easy to copy into spreadsheets, ATS tools, or documentation without reformatting.

  • Most recent employer listed first
  • Blank fields left empty for manual completion
  • Gaps under 1 month always show as "None"
  • Overlaps noted with company name for clarity
  • Currently employed roles calculate to today

// how it works

Simple by design

01
Paste the resume text
Copy any raw resume text — doesn't matter if it's messy, inconsistent, or missing punctuation. The parser handles it.
02
Claude extracts and calculates
The Anthropic Claude API reads the text, identifies all employment entries, groups roles by company, and computes tenure, gaps, and overlaps.
03
Copy the structured output
Every result is formatted identically — numbered, sorted by recency, with blank fields ready for you to fill in manually.
04
API key stays secure — always.
The Anthropic API key never touches the browser. Every request goes through a serverless backend function, so your credentials stay private and can never be extracted from the page.
